# Solar Challenge — Week 1

A data-analysis learning project completed as part of a solar data challenge.

## Overview

The project focuses on setting up a Python data-analysis workflow and preparing the project structure for exploratory analysis.

## Technologies

- Python
- Jupyter / data-analysis tooling
- Git & GitHub

## Setup

Create and activate a virtual environment, then install the project dependencies:

```bash
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```
